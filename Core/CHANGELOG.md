# Changelog

All notable changes to the AI RAT Detection Dashboard will be documented in this file.

## [1.0.0] - 2026-09-14
### Added
- Phase 1: Project structure initialized with AGENTS.md, dependencies, and environment configuration.
- Phase 2: Core configuration module, thread-safe SQLite database with schema indexes and log management.
- Phase 3: Real-time Windows system monitoring (CPU, RAM, Disk, logged-in users, process tree, and startup applications).
- Phase 4: Network connection collector correlating PIDs, socket states, port inspection, and I/O counters.
- Phase 5: Explainable rule-based behavioral risk engine with weighted scoring, anomalous path checks, port checks, and alert cooldowns.
- Phase 6: Streamlit dark SOC cybersecurity dashboard with telemetry sparklines, Plotly history graphs, and modular panels matching UI specifications.
- Phase 7: Automated report generation producing comprehensive CSV exports and professional PDF forensic summaries.
- Phase 8: Comprehensive automated test suite for database, detection engine, monitoring collectors, and reporting pipeline.
