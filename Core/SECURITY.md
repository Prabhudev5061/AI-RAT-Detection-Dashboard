# Security Policy

## Defensive Monitoring Purpose
The **AI RAT Detection & System Network Monitoring Dashboard** is exclusively designed as a defensive host security auditing and educational threat analysis tool.

It does **NOT** contain or support:
- Remote code execution or command injection mechanisms
- Credential harvesting or keylogging
- Packet tampering or offensive payload delivery
- Malicious persistence creation

## Reporting a Vulnerability

If you discover a security flaw or unintended privilege leak in this project:
1. Please do **NOT** file a public GitHub issue.
2. Privately report the issue to the maintainers with:
   - A detailed description of the vulnerability.
   - Steps or proof-of-concept to reproduce the behavior safely.
   - Impact assessment on the host environment.
3. We will acknowledge receipt within 48 hours and coordinate a patch promptly.
